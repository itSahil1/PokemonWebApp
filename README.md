🧩 PokemonMasterTracker
A feature-rich web application for tracking Pokémon mastery progress. Built using modern frontend technologies including React, Vite, TailwindCSS, and React Router, with scalable structure and optimized performance.

🚀 Features
✅ Dashboard to View All Pokémon
See a comprehensive list of Pokémon to monitor progress.

✅ Track Mastery Progress
Mark Pokémon as Caught, Mastered, or Pending status.

✅ Filter & Search Pokémon
Find specific Pokémon using filters or name search.

✅ Dynamic Routing with React Router
Navigate between views like Pokémon list, detail view, and progress overview.

✅ State Management with useState & useEffect
All progress and interactions are handled with React Hooks.

✅ Responsive & Accessible UI
Built with TailwindCSS and Shadcn UI for beautiful, mobile-friendly interfaces.

✅ Module Aliasing for Clean Codebase
Simplified imports using Vite alias setup (@components, @pages, etc.)

🛠️ Tech Stack
⚛️ React — Component-based UI library

⚡ Vite — Next-generation frontend tooling

🎨 TailwindCSS — Utility-first CSS framework

🧩 React Router — For client-side routing

🌐 Shadcn UI — Accessible and elegant UI components

🔄 useState, useEffect — Core React hooks for state and lifecycle

📁 Module Aliases — Configured in vite.config.js
